# Hotel Reservation System

## Project Description
The Hotel Reservation System is a desktop application developed using Java and JavaFX.  
The system allows users to register, log in, check room availability, reserve hotel rooms, and manage reservations through a simple graphical user interface.

This project was developed as part of the Object-Oriented Programming course requirements.

---

## Features
- User Registration
- User Login Authentication
- Room Availability Checking
- Hotel Room Reservation
- Reservation Management
- Graphical User Interface using JavaFX
- Object-Oriented Design Implementation

---

## How to Run the Project
1. Open the project in IntelliJ IDEA.
2. Make sure JavaFX libraries are configured correctly.
3. Run the `Main.java` file.
4. The application will start with the Welcome screen.
